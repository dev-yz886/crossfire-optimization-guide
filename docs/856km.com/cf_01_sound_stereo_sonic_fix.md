# CF 经典 2.0 纯净双声道与 Windows Sonic 空间音效冲突排查

> 适用硬件：3.5mm 电竞耳机 / USB 独立声卡 ｜ 核心规范：Stereo 2.0 纯净双声道 ｜ 避坑项：Windows Sonic

核心排查结论：CF 采用经典 DirectSound 纯净双声道定位引擎。系统开启 Windows Sonic 空间音效会破坏左右线性相位，导致上下楼层与掩体前后定位模糊。关闭空间音效并锁定 24位 48000Hz 是精准听声辨位的关键。

## 一、 声音控制台 (mmsys.cpl) 调优
1. `Win + R` 运行 `mmsys.cpl`；
2. 耳机属性 -> 空间音效：设为【关闭】；
3. 高级 -> 默认格式：`24 位，48000 Hz (工作室音质)`；
4. 勾选【禁用所有声音效果】。

## 二、 游戏内音频比例
- 音效音量：70% ~ 90%
- 背景音乐：0%
- 无线电语音：20% ~ 30%
