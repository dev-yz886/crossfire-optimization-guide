# CF 游戏内置语音麦克风电流底噪、回音与声卡独占模式冲突修复

> 影响场景：游戏内 V 键对讲 / 组队连麦 ｜ 故障现象：电流蜂鸣底噪 / 串麦回音 / 独占失灵

核心排查结论：CF 对讲出现刺耳电流和串麦枪声回音，主因是系统启用了立体声混音，或声卡被第三方软件独占。禁用立体声混音并解除麦克风独占控制权，可实现广播级纯净通话。

## 一、 录制设备控制台 (mmsys.cpl) 关键配置
1. `mmsys.cpl` -> 录制：彻底【禁用】立体声混音 (Stereo Mix)；
2. 麦克风属性 -> 高级：
   - 取消勾选【允许应用程序独占控制该设备】
   - 取消勾选【给予独占模式应用程序优先级】
   - 默认格式设为：`16 位，48000 Hz`
3. 级别：音量 85~95，麦克风增强不超过 +10.0 dB。
