# NVIDIA 控制面板针对 CF 的 7 项黄金级 3D 参数精细化设定

> 适用显卡：NVIDIA GeForce GTX / RTX 全系 ｜ 核心收益：提升 1% Low 帧 / 压榨DX9渲染管线

核心排查结论：CF 对现代显卡 GPU 占用率往往不足 15%，会导致显卡自动降频进入节能模式，造成掉帧。必须在 NVIDIA 面板中强制指定 crossfire.exe 为最高性能优先，开启 Ultra 低延迟。

## 一、 7 项核心参数
1. 低延迟模式：Ultra (超高)
2. 电源管理模式：最高性能优先
3. 最大帧速率：锁定刷新率 (240 / 360)
4. 纹理过滤 - 质量：高性能
5. 线程优化：开
6. 垂直同步：关
7. 着色缓存大小：10 GB
