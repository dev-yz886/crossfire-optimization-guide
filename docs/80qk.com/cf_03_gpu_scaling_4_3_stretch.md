# 240Hz/360Hz 电竞显示器在 CF 4:3 分辨率下的 GPU 缩放与色彩动态范围校正

> 核心领域：电竞显示器高刷 / 4:3 全屏拉伸 ｜ 关键技术：GPU缩放 / RGB 0-255 完全动态范围

核心排查结论：许多玩家将 16:9 屏切换为 CF 4:3 分辨率时出现黑边、色彩发白或刷新率降至 60Hz。原因在于显示器内置 Scaler 带来输入延迟且色彩被限至 16-235。必须开启 GPU 硬缩放与 RGB 完全模式。

## 一、 NVIDIA 面板 GPU 全屏拉伸
1. 显示 -> 调整桌面尺寸和位置；
2. 缩放模式选：全屏；
3. 执行缩放选：GPU；
4. 勾选“覆盖游戏和程序设置的缩放模式”。

## 二、 动态范围校准
更改分辨率 -> 使用 NVIDIA 颜色设置 -> 输出动态范围选【完全 (0-255)】。
